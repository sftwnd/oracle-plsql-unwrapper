Unwrap PL/SQL code packed by Oracle wrap

An open-source Java tool that turns objects wrapped by Oracle 10g and newer back into readable PL/SQL. Code from Oracle 7.2–9.2 is recovered on individual request, on a commercial basis, provided you hold the rights to that code.

Why you might need it

01

Lost sources

Only the wrapped package is left in the database and the original source is gone. We bring back text you can work with again.

02

Debugging legacy code

A calculation misbehaves and you cannot see what is inside. Readable code lets you find the cause.

03

Migration and support

Moving old systems to newer Oracle versions or other platforms requires knowing exactly what the code does.

Two support tracks

Open source
Oracle 10g+

Unwraps PL/SQL wrapped by Oracle 10g and newer. The Java source is open on GitHub — run it yourself.

github.com/sftwnd/oracle-plsql-unwrap
On individual request
Oracle 7.2 – 9.2

Older versions use a different packing format, so recovery is done per task — commercially, and only if you are entitled to work with the code.

Send a request

How it works

1

Take the wrapped code

A file or database object packed with the wrap utility.

2

Run the unwrapper

Oracle 10g+: run it yourself from the open repository. Oracle 7.2–9.2: send a request.

3

Get the PL/SQL source

Readable text you can study, edit and compile. Comments are not kept by wrap, so they will not appear in the result.

Terms and code ownership

The tool is meant for lawful work with code you have rights to: your own developments, a client's code, your company's legacy systems.

You must hold the rightsFor Oracle 7.2–9.2 requests we work only if you are entitled to unwrap the code and can confirm it.
Oracle's internal packages are excludedThe Oracle licence forbids reverse engineering its own internal packages, so we do not accept such requests.
Price on requestDepends on the Oracle version and the amount of code. We reply after learning about your task.

Tell us about your task

Send the Oracle version, the approximate amount of code and the grounds on which you hold the rights to it. We will reply to the same address.
